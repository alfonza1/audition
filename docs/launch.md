## Optional thread

1. Parallel agents produce alternatives quickly. Comparing their actual behavior still means juggling tabs. Audition gives that decision a focused workspace.
2. Actions match by exact role + accessible name. A missing or ambiguous control gets an explicit mismatch; the tool never silently clicks the same coordinates in a different layout.
3. Start with three working task-board examples, then connect your own localhost branches. Compare mobile layouts, pick a variant, and export feedback. Chromium runs locally.
4. Initial boundaries: named top-level controls, local HTTP apps, snapshot previews, and browser-only reset. I'd especially welcome fixtures with unusual accessible controls and feedback on per-variant mappings.
